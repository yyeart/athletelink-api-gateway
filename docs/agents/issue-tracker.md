# Issue tracker: GitLab

Issues and specs live in GitLab:
https://gitlab.com/team-anonyms/athelete-link/api-gateway

Use the glab CLI for issue and merge request operations.
Explicitly target this GitLab project because the clone also
has a GitHub remote. Check command flags with --help.

GitHub is the owner's personal portfolio repository.
Track development work in GitLab.

When a skill says "publish to the issue tracker", create a
GitLab issue. When it says "fetch the relevant ticket", read
the GitLab issue and its comments.
